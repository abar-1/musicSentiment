<h1 align="center">MoodMusic:</h1>
<p align="center">An ML based web-app that generates a playlist for the user in their spotify account using their detected mood and choice of genre(s).</p>

<h2>How it works:</h2>
1. The user selects genre(s) they would like in their recommendations
2. The user runs a facial analysis program, which utilizes a Convolutional Neural Network to classify their mood.
3. The user then should click the "Generate Playlist" button which then generates a playlist of 20 tracks in their spotify account.
